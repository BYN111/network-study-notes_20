## 📖 内容简介

本项目围绕"网络工程师"职业方向，系统整理**计算机网络基础、路由与交换、网络安全、Linux 网络配置**等学习笔记，并持续记录备考华为 HCIA-Datacom 与网络工程师软考的学习过程。

项目采用开源方式维护，欢迎通过 Issue 提出修改建议，共同完善这份中文网络学习资料。
